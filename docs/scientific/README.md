## Interpretación

La robustez frente a perturbaciones, escenarios o estaciones **no prueba por sí misma precisión geoquímica externa**. Un documento que cierra una campaña experimental no necesariamente certifica un modelo para uso operativo. Los datos y pesos grandes pueden permanecer exclusivamente en el laboratorio local.

El estado actual de modelos y releases se mantiene en [docs/models](../models/README.md). Para reproducibilidad y registro de datasets, consultar [operaciones](../operations/REPRODUCIBILITY.md).
